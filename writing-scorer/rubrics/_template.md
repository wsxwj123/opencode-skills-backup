# 自定义 rubric 填写模板

> 照此表填出你的维度表，SKILL.md 会按模式 A/B 完成评分与汇总。
> 校验规则（E8/E10）：每维必须含 名称+满分+档位（≥3档，区间无缝覆盖[0,满分]，最低档含"引不出证据"）+档内锚点；
> 满分≤0 / 档数<3 / 维度重名 / 区间未覆盖 / 模式A总分与Σ满分冲突 → 报「rubric非法」停止。
> 扣分项、等级映射、报告模板可省略，用默认值。

## 一、元信息

```
模式：A 或 B          # A=独立求和（总分=Σ维度分−扣分项，再应用cap）
                      # B=综合档次（先按等级映射定总分区间，再细分各维分）
总分：<总分>          # 模式A必填且必须 = Σ各维满分；模式B可不填
score_cap：<上限>     # 可省，默认 = 总分（A）/ 等级映射最高档上限（B）
扣分项：              # 可省，默认无。逐条写，如「错别字：每3个-1，至多-2」
```

## 二、维度表（每维照此格式填，至少 3 档，档位区间无缝覆盖 [0, 满分]）

```
维度名称：<名称>（如：立意）
满分：<数值>
档位：
- <档1>（<区间下界>-<区间上界>分）：<档位行为描述，须可观测、不抽象>
  档内锚点：<计数判据优先；无可计数判据时写"三参照兜底：参照相邻档临界分+本档典型特征，取中值附理由">
- <档2>（<区间下界>-<区间上界>分）：<档位行为描述>
  档内锚点：<同上>
- <档3>（0-<区间上界>分）：<最低档行为描述，必须含"引不出证据"字样>
  档内锚点：引不出任何原文证据 → 记0分（或 0-<分>）；其余三参照兜底
```

**区间无缝覆盖自查**：相邻档位必须「本档下限 = 上一档上限 + 1」，且最高档上限 = 满分、最低档下限 = 0。不得有缺口或重叠。

## 三、等级映射（可省，模式B必填）

```
模式A默认（省略时）：≥85%总分=优 / 70-84%=良 / 55-69%=中 / <55%=差
模式B示例：A档25-31 / B档15-24 / C档0-14
```

## 四、报告模板（可省，用默认通用模板）

```
默认通用模板：
【总体评分】XX分/总分，等级：<等级>
一、评分依据：逐维 <维度名> <得分>/<满分> + 档位对照 + 档内定分理由 + 原文证据
二、逐维修改建议
三、（若用户要求优化全文）优化版
```

## 五、模式 A/B 说明

- **模式A（独立求和）**：逐维独立定档定分（每维引证据）→ 总分 = min(Σ维度分 − 扣分项, cap)。
  例：立意 8/10 + 结构 7/10 = 15，扣错别字 0.5 → 14.5，cap 20 → 14.5。
- **模式B（综合档次）**：先整体定档（等级映射区间）→ 在该区间内定总分，再分解为各维分
  （Σ维分 = 总分，各维仍须引证据）→ 总分 = min(总分 − 扣分项, cap)。
  例：等级映射 A档25-31，定 27 分 → 内容14+结构8+语言5=27，扣 2 → 25。
