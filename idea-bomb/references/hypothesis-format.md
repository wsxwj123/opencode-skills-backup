# 摘要式假说：写成立项依据的样子

第二段的产物。一个种子展开成这样一份东西，才算成型的课题假说，才允许进库。

## 文体基准：国自然立项依据

**产出的参照系是基金申请书的立项依据，不是聊天，也不是综述摘要。** 读者是评审专家，他要在这段文字里看到一条完整的论证链，不是一组信息条目。

权威规范在 `~/.claude/skills/nsfc-proposal/references/03_写作规范与反AI.md`，动笔前读它。下面是本技能必须守住的部分。

### 段落式叙事，这是第一条

全文用完整段落展开，**禁止用项目符号或编号列表展开论述**。把论点切成条目，评审看到的是 PPT 提纲，不是科学故事。这是以往产出最大的毛病。

每段 150 到 400 字，段内有主题句、展开句、过渡句。段落之间靠逻辑衔接，不靠标号切换话题。

四要素是内容上的四件事，不是四个必须顶小标题的区块。可以分节，但每节内部必须是段落，不能是条目。

### 立项依据的叙事线

按这条线组织，不要跳步：

宏观背景，即这个领域的问题是什么，然后聚焦到具体对象，接着交代国内外研究现状，即已经知道什么、谁做的、什么结论，再点出关键空白或矛盾，即还不知道什么，然后给出本方向的切入点，即凭什么能做，最后凝练科学问题，即到底要回答什么。

### 引用

立项依据必须挂文献。论断后面跟编号引用，格式是 `[1]`、`[2,3]`。不写"大量研究表明"，写"Zhang 等[1]与 Li 等[2]的研究表明"。不写"近年来"，写具体年份范围。

文末列参考文献，编号对应正文，每条给作者、期刊、年份、PMID 或 DOI。只列真实检索到的文献。

### 术语解释融进叙事

概念要解释，但**不许单列一节加粗条目**。解释写进句子，跟着论证走。

不合格（条目式，读者看到的是词典）：

> **O 抗原与血清型**：O 抗原是革兰阴性菌外膜脂多糖最外层的重复多糖链，是宿主抗体识别的主要靶点。

合格（融进叙事）：

> 静脉给予的治疗菌在到达肿瘤之前须先耐受宿主的血流清除，决定其清除速度的主要表面成分是 O 抗原，即革兰阴性菌外膜脂多糖最外层的重复多糖链。该多糖链暴露于菌体表面，免疫原性强，其结构型别同时决定菌株的血清型。

判定研究者熟不熟一个词，以 `profile.md` 为准。超出那个范围的概念，首次出现必须在同一句里讲清楚。

### 反 AI 的具体禁令

这些句式一个都不许出现：

不是……而是……；不仅……而且……；值得注意的是；需要指出的是；至关重要；不可或缺；具有重要的理论意义和实践价值；日益增长；蓬勃发展；深入探讨；系统研究；全面分析。

修辞禁令：排比、反问、设问、夸张（革命性的、颠覆性的）。

标点禁令：装饰性破折号；给术语加的引号；解释性冒号，写"X 是指……"，不写"X：……"。

另外两条容易犯。

**不要回避系动词。** 写"A 是调控枢纽"，不写"A 充当调控枢纽"。写"该通路有独特功能"，不写"该通路具备独特功能"。把"是"改成充当、扮演、具备，只会更生硬。

**同一段内概念称谓必须统一。** 段首定了叫 O 抗原，整段都叫 O 抗原，不要交替用 O 多糖、脂多糖外层。缩写首次出现写全称加括号，之后统一用缩写。

### 节奏

短句和长句交替，不要连续三句长度差不多。连续两段不要用同样的结构开头，不要连着用"本研究""本项目"起头。

### 自检

产出写完后跑一遍反 AI 脚本：

```bash
python3 ~/.claude/skills/nsfc-proposal/scripts/humanizer_zh.py scan <文件>
```

`count` 不为零就按报告逐条改。长句属软提醒，机制类严密长句可以保留。脚本查不出叙事线和段落式这两条，那要自己对着上面的要求核一遍。

## 四要素的内容要求

### ① 研究背景 `background`

领域局面加研究现状。要有具体的人、具体的结论、具体的引用，不是泛泛陈述。

写对的样子：

> 瘤内活菌治疗依赖兼性厌氧菌在实体瘤乏氧核的自发定植，是近十年肿瘤靶向递送的一条独立路线。该策略的疗效在不同批次之间波动明显，Zhang 等[1]将其归因于菌株传代过程中的活性衰减，Li 等[2]则报道瘤内乏氧程度的个体差异可解释部分方差。两项工作共同的前提是给药时刻不影响结果，因而现有剂量学研究均按固定时间点给药。

写错的样子有三种。空泛开场不给信息，例如"近年来，肿瘤微环境调控已成为研究热点"。口语叙述，例如"活菌治疗每批效果差得挺多"。条目切块，把研究现状拆成三个加粗小点各写一句。

### ② gap `gap`

前人漏掉的那一块，能被一句话点名。承接背景段的最后一句，不要另起炉灶。

> 宿主固有免疫细胞的数量与活性以约二十四小时为周期波动，这一节律现象在感染模型中已有明确证据[3]。活菌治疗的剂量学研究默认给药时刻与疗效无关，该前提迄今未经直接检验。

自检：把 gap 改写成"既往研究未开展 X"，X 必须是一项具体的研究动作。只能写成"深入研究"就不合格。

### ③ 研究思路与设计 `design`

怎么验。写到大概的实验内容为止，用什么体系、比什么、看什么读出。**不写详细方案**，不列分组表、不列时间点、不写剂量和统计方法。

> 于两个相位点向荷瘤小鼠给予同批次工程菌，比较瘤内定植量、细菌清除速率与肿瘤生长曲线。进一步在节律基因敲除小鼠中重复上述比较，据此判定差异是否依赖宿主节律。

两三句说明验证路径即止。详细方案等研究者指定方向后另议。

### ④ 创新点 `innovation`

新在哪，一句话，经得起"那又怎样"的追问。

> 将时间生物学的相位变量引入活菌治疗剂量学，为疗效优化提供一个无需增加成本的给药调度维度。

不写"首次提出""填补空白"。查新结果写在 `closest_work` 与 `diff` 字段，本栏陈述的是价值。

## 证伪点 `falsification`

这一条最容易写成敷衍，也最见功力。它不是"可行性风险"，是"什么结果出来就说明我错了"。

要落到结构上，两步。第一步点名承重变量，即假设真正压在哪个因素身上，不是"这个机制"，是那一个具体的变量。第二步配一个非同义反复的阴性对照，把承重变量拿掉，下游指标就该回落到基线。

> 承重变量为给药时刻对应的固有免疫细胞丰度差异。若在节律基因敲除小鼠中，两个相位点间的瘤内定植量差异消失，则本假设被证伪。

反例（同义反复，不管结果怎样都证伪不了什么）：

> 若工程菌无法在肿瘤定植，则本方案失败。

这句话说的是实验没做成，不是假设不成立。换个说法其实跟假设本身等价的对照，一律不算证伪点。

自检：那个"拿掉某某"的操作，是不是真能把假设的承重部分单独拿掉？拿掉之后如果指标没回落，会不会真的承认自己错了？两个都是"是"才算过关。

## 查新证据

`novelty_queries` 填实际跑过的检索式。别编。脚本查不出真假，但引一条不存在的文献是红线。

跨界迁移（`method=transfer`）必须给至少两条：一条搜目标领域，一条用源领域的原名再搜一遍。撞车最可能发生在源领域那头，那边早做过、只是换了套说法，只搜目标领域根本看不见。

`closest_work` 写最接近的那篇真实结果。确实没搜到就如实写"检索未见直接先例"，这是合法结论，此时 `diff` 可以留空。写了具体工作就必须写清差异点，不许用"—"或"无"顶替。

## 提交用的 JSON 形状

```json
{
  "idea": "一句话说清这个课题是什么（≥30 字）",
  "hypothesis": {
    "background": "……", "gap": "……", "design": "……", "innovation": "……"
  },
  "feasibility_layers": {
    "机制": "外域机制搬过来在本领域讲不讲得通",
    "体系实现": "在用户的体系里能不能真做出来，关卡看 profile",
    "三年立项": "三年内的条件够不够"
  },
  "falsification": "承重变量 + 非同义反复的阴性对照",
  "novelty_queries": ["目标领域检索式", "源领域原名检索式"],
  "closest_work": "PMID 38123456（……）",
  "diff": "和最接近的那篇差在哪（≥10 字；无先例时可留空）",
  "novelty": "中-高",
  "feasibility": "高",
  "quadrant": "甜区（创新中-高×可行高）",
  "source_domain": "时间生物学",
  "source_mechanism": "免疫细胞丰度的昼夜相位",
  "platform": "工程化细菌",
  "disease": "实体瘤",
  "method": "transfer",
  "status": "untried",
  "user_verdict": "采纳"
}
```

`feasibility_layers` 的键名随便起，只要有三层、每层 ≥10 字。`source_domain` / `source_mechanism` 是跨界迁移专用的，组合重组和换角度可以不写。`schema`、`date`、`committed_at`、`seed_id`、`archived` 由脚本自己填，写了也会被覆盖。

JSON 是入库用的结构，呈现给研究者时不要原样输出。正文按立项依据体写成连贯段落，口头讲解取舍时用平实中文。两者文体不同，不要互相污染。
