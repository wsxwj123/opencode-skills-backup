# 摘要式假说：四要素怎么写

第二段的产物。一个种子展开成这样一份东西，才算成型的课题假说，才允许进库。

四要素缺一不可：研究背景、gap、研究思路与设计、创新点。四段合起来控制在一屏内，不是标书，也不是实验方案。

**文体是学术书面语，对着期刊摘要写，不是对着聊天写。** 第三人称陈述，不出现"你""我"；用完整主谓结构，不用省略句；不用反问、设问、口语连接词。详见 SKILL.md《怎么说，怎么写》第二节。下面每个范例都按这个文体给出，照着写。

**书面化不等于可以堆术语。** 凡超出研究者主平台范围的概念，首次出现必须当场解释。四要素之前先给一个《关键概念》小节，把该方向依赖的外域概念列清楚。规则见 SKILL.md《术语与概念》。

## 关键概念（四要素之前先写这个）

该方向依赖的、超出研究者主平台的概念，逐条列出，通常 2 到 5 条。每条一到两句：这个东西是什么，在本方向里起什么作用。依赖的外域概念不足两条时可以省略本节，但正文里不得留下未解释的名词。

写对的样子：

> **O 抗原**：革兰阴性菌外膜脂多糖最外层的重复多糖链，是细菌表面免疫原性最强的成分，宿主抗体主要识别它。其结构型别决定该菌的血清型。
>
> **调理作用**：抗体结合细菌表面后，吞噬细胞通过识别抗体尾部而高效吞噬该细菌的过程。抗体滴度越高，细菌在血流中存活时间越短。
>
> **糖基化相变**：部分细菌可通过可逆的基因开关改变 O 抗原糖链的修饰状态，使同一菌株在不同时期呈现不同血清型。本方向拟把这一天然开关改造为外源可控元件。

写错的样子（术语原样搬出，读者接不住）：

> 本方向利用 gtrC III 介导的 O 抗原糖基化相变，在 OxyR/Dam 共调控下实现血清型 ON/OFF 切换以规避调理化清除。

## 四要素

### ① 研究背景 `background`

这个问题现在是什么局面。一到三句，落到具体的现象和已有做法上，不要"随着……的发展"这种开场。

写对的样子：

> 瘤内活菌治疗依赖兼性厌氧菌在实体瘤乏氧核的定植，其疗效存在显著批间波动。现有解释集中于菌株活性差异与瘤内乏氧程度。昼夜节律是指生理指标以约二十四小时为周期的自发波动，宿主固有免疫细胞的数量与活性同样受其调控。给药时刻是否因此影响细菌定植与清除，迄今未见系统考察。

该范例的结构值得照搬：先陈述研究者本来就熟悉的局面（活菌治疗、乏氧定植、疗效波动），再引入外来概念并当场解释（昼夜节律），最后落到问题。开篇第一句不出现生词。

写错的样子有两种。

空泛开场，不给信息：

> 近年来，肿瘤微环境调控已成为研究热点，工程菌治疗展现出巨大潜力。

口语叙述，信息有但文体不合：

> 活菌治疗每批效果差得挺多，大家都往菌株活性和乏氧上想，没人系统看过给药时刻这件事。

合格的背景应当满足：读者读完能够就该现象提出下一个具体问题；同时全段可直接置入摘要而无需改写文体。

### ② gap `gap`

前人漏掉的那一块，必须是能被一句话点名的空白，不是"研究还不够深入"。

好的 gap 通常长这样：某个被默认成立的前提，其实从没被直接检验过；或者两条各自成熟的线，没人把它们接起来过。

> 固有免疫细胞丰度呈昼夜节律波动，而现有活菌治疗剂量学研究均默认给药时刻不影响疗效。该前提迄今未经直接检验。

自查标准：将 gap 改写为"既往研究未开展 X"后，X 须为一项具体的研究动作。若 X 只能写成"深入研究"或"系统探讨"，则不合格。

### ③ 研究思路与设计 `design`

怎么验。写到大概的实验内容为止：用什么体系、比什么、看什么读出。

**不要写成详细实验方案**。不列分组表、不列时间点、不写剂量和统计方法。那是用户选定方向之后另议的事。

> 于两个相位点向荷瘤小鼠给予同批次工程菌，比较瘤内定植量、细菌清除速率与肿瘤生长曲线；进一步在节律基因敲除小鼠中验证上述差异是否依赖宿主节律。

两至三句说明验证路径即止。详细方案待研究者指定方向后另行展开。

### ④ 创新点 `innovation`

新在哪，一句话。要能经得起"那又怎样"的追问——说清楚它带来什么别人拿不到的东西。

> 将时间生物学的相位变量引入活菌治疗剂量学，为疗效优化提供一个无需增加成本的给药调度维度。

不写"首次提出""填补空白"。查新结果写在 `closest_work` 与 `diff` 字段，本栏陈述的是该方向能提供而他处不能提供的价值。

## 证伪点 `falsification`

这一条最容易写成敷衍，也最见功力。它不是"可行性风险"，是"什么结果出来就说明我错了"。

要落到结构上，两步：

1. **点名承重变量。** 你的假设真正压在哪个因素身上？不是"这个机制"，是那一个具体的变量。
2. **配一个非同义反复的阴性对照。** 把承重变量拿掉，下游指标就该回落到基线。

> 承重变量为给药时刻对应的固有免疫细胞丰度差异。若在节律基因敲除小鼠中，两个相位点间的瘤内定植量差异消失，则本假设被证伪。

反例（同义反复，不管结果怎样都证伪不了什么）：

> 若工程菌无法在肿瘤定植，则本方案失败。

这句话说的是实验没做成，不是假设不成立。换个说法其实跟假设本身等价的对照，一律不算证伪点。

自查：你的证伪点里，那个"拿掉某某"的操作，是不是真能把假设的承重部分单独拿掉？拿掉之后如果指标没回落，你会不会真的承认自己错了？两个都是"是"才算过关。

## 查新证据

`novelty_queries` 填你实际跑过的检索式。别编。脚本查不出真假，但引一条不存在的文献是红线。

跨界迁移（`method=transfer`）必须给至少两条：一条搜目标领域，一条用源领域的原名再搜一遍。撞车最可能发生在源领域那头——那边早做过、只是换了套说法，只搜目标领域根本看不见。

`closest_work` 写最接近的那篇真实结果。确实没搜到就如实写"检索未见直接先例"，这是合法结论，此时 `diff` 可以留空。写了具体工作就必须写清差异点，不许用"—"或"无"顶替。

## 提交用的 JSON 形状

```json
{
  "idea": "一句话说清这个课题是什么（≥30 字）",
  "hypothesis": {
    "background": "……", "gap": "……", "design": "……", "innovation": "……"
  },
  "feasibility_layers": {
    "机制": "外域机制搬过来在本领域讲不讲得通",
    "体系实现": "在用户的体系里能不能真做出来，关卡看 profile",
    "三年立项": "三年内的条件够不够"
  },
  "falsification": "承重变量 + 非同义反复的阴性对照",
  "novelty_queries": ["目标领域检索式", "源领域原名检索式"],
  "closest_work": "PMID 38123456（……）",
  "diff": "和最接近的那篇差在哪（≥10 字；无先例时可留空）",
  "novelty": "中-高",
  "feasibility": "高",
  "quadrant": "甜区（创新中-高×可行高）",
  "source_domain": "时间生物学",
  "source_mechanism": "免疫细胞丰度的昼夜相位",
  "platform": "工程化细菌",
  "disease": "实体瘤",
  "method": "transfer",
  "status": "untried",
  "user_verdict": "采纳"
}
```

`feasibility_layers` 的键名随便起，只要有三层、每层 ≥10 字。`source_domain` / `source_mechanism` 是跨界迁移专用的，组合重组和换角度可以不写。`schema`、`date`、`committed_at`、`seed_id`、`archived` 由脚本自己填，写了也会被覆盖。

呈现给研究者时不要把 JSON 原样输出，按 SKILL.md《怎么说，怎么写》执行：假说正文各字段用学术书面语，口头讲解取舍时用平实中文。两者文体不同，不要互相污染。
